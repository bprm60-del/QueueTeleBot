# 🎓 ITMO Queue Bot (Бот очередей на сдачу лабораторных / ДЗ)

## All documentations and annotations are built by LLM
## database.py, config.py is made not by AI

Telegram-бот для организации электронных очередей студентов на сдачу лабораторных и домашних работ в Университете ИТМО.

---

## 🚀 Основные возможности

1. **Любая группа ИТМО**:
   - Бот поддерживает формат групп ИТМО: **1 буква + 4 цифры** (например, `M3101`, `K3240`, `P3311`, `B3100`, `N3245`).
   - Администратор может создавать слоты расписания для **любых групп** — они автоматически добавляются в базу данных.
2. **Данные студента**:
   - При первом запуске бот запрашивает **ФИО полностью** (Фамилия Имя Отчество) и **номер группы**.
   - Профиль можно в любой момент отредактировать.
3. **Ограничение записи — максимум 2 недели**:
   - Запись и создание слотов сдачи ограничены горизонтом в **14 дней** от текущей даты.
4. **Удаление предыдущих записей**:
   - Встроена система автоочистки (`cleanup_old_entries`), которая автоматически удаляет прошедшие слоты и записи из базы.
   - Администратор может в 1 клик очистить очередь («🧹 Очистить очередь») или удалить слот.
   - Функция «📢 Вызвать следующего» удаляет первого студента из очереди и отправляет ему личное уведомление о вызове.
5. **Админ-панель для того, кто разворачивает сервер**:
   - Назначение администраторов через Telegram ID в файле `.env`.
   - Добавление слотов расписания с указанием группы, предмета, даты, времени и лимита мест.
   - Просмотр всех очередей в реальном времени, вызов студентов, удаление слотов.

## 🛠 Установка и запуск

### 1. Установка библиотек

Откройте командную строку или PowerShell в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

### 2. Настройка файла `.env`

Откройте файл `.env` в любом текстовом редакторе (Блокнот, VS Code и т.д.):

```ini
# Токен бота, полученный у @BotFather
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Ваш числовой Telegram ID (можно узнать у бота @userinfobot)
# Если администраторов несколько, укажите их через запятую: 123456789,987654321
ADMIN_IDS=ВАШ_TELEGRAM_ID
```

### 3. Запуск бота

Выполните команду:

```bash
python bot.py
```

После этого бот начнет опрос серверов Telegram и будет готов к работе.

## 📱 Сценарии использования

### 🧑‍🎓 Для студентов:
1. Запустить бота командой `/start`.
2. Ввести ФИО (Фамилия Имя Отчество).
3. Ввести номер группы (буква + 4 цифры).
4. Нажать **«📋 Расписание и запись»**, выбрать доступную сдачу и нажать **«🙋‍♂️ Встать в очередь»**.
5. Во вкладке **«🙋‍♂️ Мои очереди»** можно отслеживать свой порядковый номер или выйти из очереди при необходимости.

### 👨‍🏫 Для администратора / преподавателя:
1. Открыть бота и нажать **«⚙️ Админ-панель»** (или отправить команду `/admin`).
2. **Добавить сдачу (слот)**:
   - Указать номер группы (например, `M3101`).
   - Название предмета / лабораторной (например, `Веб-программирование ЛР №2`).
   - Дату сдачи (в пределах 14 дней от текущей даты, например `30.09.2026`).
   - Время сдачи (например, `10:00`).
   - Лимит мест (число или `0`, если лимита нет).
3. **Управление очередью**:
   - В разделе **«📅 Список расписания»** выбрать нужную пару.
   - Просмотреть список записавшихся студентов.
   - Нажать **«📢 Вызвать следующего»** — студент получит уведомление, а следующий в списке сдвинется вперед.
   - Нажать **«🧹 Очистить очередь»** для удаления всех записей после окончания сдачи.
